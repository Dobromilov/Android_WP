# Android_WP
Добромилов Артём Александрович ИКС-433

Проект содержит несколько лабораторных работ по разработке под Android:

## Функциональность приложения

### 1. Главный экран (Hub)
- Центральное Activity с навигацией ко всем функциям приложения
- Кнопки для перехода между различными активностями

### 2. Калькулятор
- Простой калькулятор с базовыми арифметическими операциями
- **Элементы интерфейса:**
  - Цифровые кнопки (0-9)
  - Кнопки операций (+, -, *, /, =)
  - TextView для отображения ввода и результатов
- **Функциональность:** обработка нескольких математических операций

### 3. Медиаплеер
- Воспроизведение аудиофайлов с устройства
- **Основные функции:**
  - Воспроизведение и пауза треков
  - Регулировка громкости
  - SeekBar для отображения прогресса и перемотки
  - Автоматическая пауза при сворачивании приложения
  - Отображение списка доступных треков
- **Особенности:** работа с разрешениями для доступа к хранилищу 

### 4. Геолокация и дистанционное управление (ZMQ)

Модуль трансляции геоданных на удаленный сервер с поддержкой обратной связи и фильтрации.

* **Отображаемые и передаваемые данные:**
* Широта (Latitude)
* Долгота (Longitude)
* Высота (Altitude)
* Метка времени (Timestamp)


* **Сетевое взаимодействие (ZeroMQ):**
* Реализован паттерн **REQ-REP** для обмена данными с Backend-сервером (C++).
* Использование библиотеки `ZMQ` для работы с сокетами в Android-сервисе.

* **Двустороннее управление и фильтрация:**
* **Remote Control:** Приложение принимает управляющие команды от сервера в каждом ответе.
* **Smart Filtering:** На стороне смартфона реализована логика фильтрации данных. Если сервер отключает какой-либо параметр (через GUI на C++), приложение перестает включать его в пакет.
* **Оптимизация трафика (Sparse JSON):** Благодаря настройке `explicitNulls = false`, отключенные поля полностью удаляются из JSON-строки, минимизируя размер сетевого пакета.


* **Технологии:**
* Работа с `LocationManager` и `GPS_PROVIDER`.
* Сериализация данных через `kotlinx.serialization`.
* Потокобезопасная передача данных через `AtomicReference`.
* Динамическая обработка Runtime Permissions.


## 🛠 Технические особенности

* **Архитектура:** Multiple Activities с главным Hub.
* **Сетевой стек:** ZeroMQ (JeroMQ) для высокопроизводительного обмена сообщениями.
* **Формат данных:** JSON (библиотека `kotlinx-serialization`).
* **Минимальная версия Android:** API 21 (Lollipop).
* **Используемые компоненты:**
* `MediaPlayer` для воспроизведения аудио.
* `Location Services` для работы с геолокацией.
* `ZContext` и `ZMQ.Socket` для сетевой связи.
